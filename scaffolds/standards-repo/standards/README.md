# __Name__ standards

Accepted standards only. Each document states `**Status:** Accepted` and lists its sources.

## Precedence

1. The human's explicit instruction.
2. A project's own instructions, architecture and decision records.
3. Decisions in `decisions/`.
4. These standards.
5. Judgement, stated as judgement.

## Keywords

**MUST** is a hard requirement; **SHOULD** is the default, deviated from only with a stated reason;
**MAY** is optional.

## Provenance

Every standard here came from evidence: two or more sources showing the same practice, recorded in
`docs/provenance.md`. A standard that describes current state is labelled as such, separately from
the procedure a new system follows.
